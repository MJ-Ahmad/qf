# পোর্টাল গেটওয়ে — নতুন অ্যাকাউন্ট যোগ করার ধাপ

হোমপেজের যেকোনো পোর্টাল-লিংকে (হিফজ পোর্টাল, ডোনার পোর্টাল, সাপোর্টার, বিনিয়োগকারী পোর্টাল, বিতরণ ব্যবস্থাপনা) ক্লিক করলে সবাই এই একই গেটওয়েতে (`portal_gateway/`) আসবে। লিংকে `?role=investor` এর মতো প্যারামিটার দিলে রোল-বাছাই স্ক্রিন এড়িয়ে সরাসরি সেই রোলের লগইন খুলবে।

এখানে কোনো ডেমো ইউজারনেম/পাসওয়ার্ড বা "শীঘ্রই আসছে" ব্যাজ নেই। প্রতিটি রোল একই নিয়ম মেনে চলে — ব্যতিক্রম নেই, "দায়িত্বশীল ব্যবস্থাপনা"ও অন্য সবগুলোর মতোই তার নিজস্ব ফোল্ডার-প্যাটার্নে থাকে, আলাদা করে সরাসরি অন্য কোনো সিস্টেমে লিংক করা হয় না।

## ফাইল কাঠামো

```
portal_gateway/
├── index.html                  ← রোল-বাছাই + লগইন পাতা (?role= সাপোর্ট করে)
├── data.json                    ← রোলের তালিকা ও প্রতিটি রোলের users[]
├── hash-generator.html          ← নতুন পাসওয়ার্ডের SHA-256 হ্যাশ তৈরির টুল (নিজের জন্য, পাবলিশ করবেন না)
├── responsible/_template/       ← টেমপ্লেট
├── investor/
│   ├── _template/                ← বিনিয়োগকারীর জন্য চূড়ান্ত টেমপ্লেট (চুক্তি + লেজার + রিটার্ন হিসাব)
│   └── alamin/                   ← হাফেজ আল আমিনের প্রকৃত প্রোফাইল
├── donor/
│   ├── _template/                ← দাতার জন্য টেমপ্লেট (অনুদান + বিতরণ রেকর্ড)
│   └── abdullah/                 ← মোঃ আব্দুল্লাহর প্রকৃত প্রোফাইল
├── supporter/
│   ├── _template/                ← সাপোর্টারের জন্য টেমপ্লেট (শর্তহীন সহায়তার রেকর্ড)
│   ├── rafika-sultana/
│   ├── arefa-begum/
│   ├── tarikul-haque/
│   └── delowar-hossain/
└── distribution/                 ← বিতরণ নেটওয়ার্ক/রেকর্ড সংগঠিত করার কাঠামো (এখনো খালি, ধাপে ধাপে পূরণ হবে)
```

## একজন নতুন ব্যবহারকারী যোগ করার ধাপ

১. `hash-generator.html` খুলুন, পাসওয়ার্ড থেকে SHA-256 হ্যাশ তৈরি করুন। প্লেইন পাসওয়ার্ড কোথাও লিখে রাখবেন না।

২. `data.json`-এ সংশ্লিষ্ট role খুঁজুন (যেমন `"id": "donor"`), তার `"users"` অ্যারেতে যোগ করুন:
```json
{ "username": "abdullah", "passwordSha256": "<হ্যাশ>", "displayName": { "bn": "মোঃ আব্দুল্লাহ", "en": "Md. Abdullah" } }
```

৩. সংশ্লিষ্ট role এর `_template/` ফোল্ডার কপি করে `{folder}/{username}/` নামে রাখুন — ফোল্ডারের নাম অবশ্যই `username`-এর সাথে হুবহু মিলতে হবে।

৪. সেই ফোল্ডারের `data.json`-এ প্রকৃত তথ্য বসান। লগইন করে পরীক্ষা করুন।

## MJ-Node ব্যাকএন্ড সম্পর্কে অবস্থান

এই মুহূর্তে প্রমাণীকরণ (login check) সম্পূর্ণ স্ট্যাটিক — ব্রাউজারে `data.json`-এর `passwordSha256`-এর সাথে তুলনা করা হয়। যেহেতু `data.json` পাবলিকলি fetch করা যায়, এটি প্রকৃত সার্ভার-সাইড নিরাপত্তা দেয় না, শুধু একটি প্রাথমিক UI-স্তরের প্রবেশদ্বার। MJ-Node ব্যাকএন্ড প্রস্তুত হলে এখানকার লগইন-লজিক তার API দিয়ে প্রতিস্থাপন করা হবে — সেই পর্যন্ত সাইটে কোথাও এমন কিছু বলা হচ্ছে না যে এটি বাস্তবে সুরক্ষিত।
